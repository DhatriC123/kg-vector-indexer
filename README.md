# kg-vector-indexer

Reusable Python library and CLI for turning `microservice-kg` graph output plus source code into vector-searchable code chunks.

## What it does

- Reads `service-graph.json` generated by `microservice-kg`
- Extracts Java method-level chunks from real source files
- Generates embeddings through a pluggable embedding provider
- Stores chunks and metadata in ChromaDB
- Lets you query indexed chunks later

## Current scope

- Java method-level chunk extraction
- ChromaDB persistence
- Pluggable embedding provider interface
- Deterministic chunk metadata linked to graph IDs
- KG-first retrieval with vector fallback

This keeps responsibilities separated:

- `graph/` for reading `microservice-kg` output
- `indexing/` for chunk extraction and Chroma indexing
- `embeddings/` for embedding providers
- `retrieval/` for KG-first retrieval and ranking
- `storage/` for vector-store adapters

## Quick start

1. Create a virtual environment
2. Install dependencies
3. Configure repo and graph paths
4. Run the indexer

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
kg-index \
  --repo-path /Users/a50082/IdeaProjects/fin-lead-service-new \
  --graph-path /Users/a50082/IdeaProjects/fin-lead-service-new/.microservice-kg/service-graph.json \
  --chroma-path /Users/a50082/IdeaProjects/kg-vector-indexer/chroma_data \
  --collection lead_code_chunks
```

Example query:

```bash
kg-query \
  --chroma-path /Users/a50082/IdeaProjects/kg-vector-indexer/chroma_data \
  --collection lead_code_chunks \
  --query "lead creation flow" \
  --limit 3
```

KG-first retrieval with vector fallback:

```bash
kg-retrieve \
  --graph-path /Users/a50082/IdeaProjects/fin-lead-service-new/.microservice-kg/service-graph.json \
  --chroma-path /Users/a50082/IdeaProjects/kg-vector-indexer/chroma_data \
  --collection lead_code_chunks \
  --query "which endpoint handles lead creation?" \
  --limit 5
```

## Metadata contract

Each chunk is stored with:

- `chunkId`
- `repoId`
- `serviceId`
- `classId`
- `methodId`
- `filePath`
- `startLine`
- `endLine`
- `type`

This keeps the vector DB aligned with the graph produced by `microservice-kg`.
